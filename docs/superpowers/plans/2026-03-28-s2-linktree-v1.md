# S2-Linktree V1 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox syntax for tracking.

**Goal:** Build a Neo-Brutalism academic resource hub with category card grid, full CRUD, search, theme toggle, and data export/import.

**Architecture:** Next.js 14+ App Router, Zustand (localStorage persist), Tailwind CSS, Framer Motion. Single-page app, feature-based folder structure.

**Tech Stack:** Next.js, React 18, TypeScript, Zustand, Tailwind CSS, Framer Motion, nanoid, Vitest, React Testing Library

**Spec:** `docs/superpowers/specs/2026-03-28-s2-linktree-design.md`

---

## Plan Structure

The plan is split into 4 chunk files for manageability:

1. **Chunk 1** (`chunk1-setup-data.md`): Project scaffold, types, utils, constants, animations, stores, hooks — all non-UI code
2. **Chunk 2** (`chunk2-theme-ui.md`): Theme system (globals.css, layout), reusable UI components (Button, Input, Modal, ThemeToggle, Toast, EmojiPicker)
3. **Chunk 3** (`chunk3-display-features.md`): Display components (LinkItem, CategoryCard, CategoryGrid, SearchBar, HeroSection, HomePage, page.tsx)
4. **Chunk 4** (`chunk4-management-integration.md`): CRUD modals (AddLink, EditLink, AddCategory, EditCategory, DeleteConfirm), build verification

Execute chunks sequentially. Each chunk commits after every task.

## Testing Strategy

- **Store tests** (Vitest, no DOM): CRUD, cascade delete, import/merge
- **Utils tests** (Vitest): URL validation, extraction, cn
- **Hook tests** (Vitest + RTL renderHook): Filtering logic
- **Build check**: `next build` must succeed
- **All tests**: `npx vitest run` must pass
