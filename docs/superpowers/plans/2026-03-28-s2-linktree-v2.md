# S2-Linktree V2 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove import/export features, add WebGL 3D animated background with mouse parallax, and add drag-and-drop card/link reordering with cross-category support.

**Architecture:** Three surgical changes to an existing Next.js 16 app. Feature removal is purely subtractive. 3D background uses React Three Fiber in a lazy-loaded fixed layer behind content. DnD uses @dnd-kit with wrapper components around existing CategoryCard/LinkItem, orchestrated by a central hook. All state changes flow through Zustand store with auto-persistence.

**Tech Stack:** Next.js 16.2.1, React 19, TypeScript 5, Zustand 5, Framer Motion 12, Tailwind CSS v4, React Three Fiber, @react-three/drei, @react-three/postprocessing, @dnd-kit/core, @dnd-kit/sortable, @dnd-kit/utilities, Vitest 4, @testing-library/react

**Spec:** `docs/superpowers/specs/2026-03-28-s2-linktree-v2-design.md`
